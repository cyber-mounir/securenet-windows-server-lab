# SecureNet Lab

## Project Overview

 SecureNet Lab is a personal learning project focused on designing and implementing a secure Windows Server infrastructure in a virtualized environment.

# The project simulates a small company with two departments: Human Resources (HR) and Commercial.

## Project Objectives

- Build a virtualized infrastructure using VMware Workstation and Proxmox VE.

- Configure network segmentation using VLANs.

- Implement firewall and routing services using OPNsense.

- Deploy Windows Server with Active Directory, DNS and DHCP.

- Configure a File Server with department-based access permissions.

- Secure communication between network segments.

- Test and document the complete infrastructure.

## Technologies

- VMware Workstation
- Proxmox VE
- OPNsense
- Windows Server
- Active Directory
- DNS and DHCP
- Cisco Packet Tracer
- Git and GitHub

## Project Scope
 This is a personal learning lab. It is designed for educational purposes and does not represent a production deployment.
