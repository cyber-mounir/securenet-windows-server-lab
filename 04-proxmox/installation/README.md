# Proxmox VE Installation

## Objective

Document the installation of Proxmox Virtual Environment (VE) 9.2-1 inside VMware Workstation.

## Environment

- Hypervisor: VMware Workstation
- Operating System: Proxmox VE 9.2-1
- Deployment: Nested Virtualization

## Installation Procedure

1\. Create a new virtual machine in VMware Workstation.
2\. Configure CPU and memory resources.
3\. Configure the virtual disk.
4\. Attach the Proxmox VE ISO image.
5\. Enable nested virtualization.
6\. Start the virtual machine.
7\. Follow the Proxmox VE installation wizard.
